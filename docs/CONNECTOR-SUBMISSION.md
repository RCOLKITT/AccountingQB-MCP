## Auth (technical detail for the form)

- OAuth 2.1 authorization-code + PKCE (S256).
- Dynamic Client Registration (RFC 7591): `https://accountingqb.com/api/oauth2/register`
- AS metadata (RFC 8414): `https://accountingqb.com/.well-known/oauth-authorization-server`
- Protected-resource metadata (RFC 9728) served by the MCP host:
  `https://mcp.accountingqb.com/.well-known/oauth-protected-resource`
- Every tool carries `readOnlyHint`/`destructiveHint` annotations
  (mcpb/manifest.json, regenerated by scripts/generate-schemas.py).

## Reviewer instructions (paste into the submission)

1. Add the connector: Settings → Connectors → Add custom connector →
   `https://mcp.accountingqb.com/mcp`.
2. When prompted to sign in, create an account (any email) and enter the
   reviewer license key **`LK-DEMO-REVIEW2026`** when asked to link a
   license, then approve access.
3. The reviewer license runs in **demo mode**: every tool returns realistic
   sample data for a fictional company (Acme Consulting LLC) and never
   contacts Intuit. Write tools simulate and clearly say so — no data is
   created anywhere.

**Example prompts:**
1. "What's my profit and loss for this year?"
2. "Find any uncategorized transactions and suggest categories."
3. "Create a $250 invoice for Acme Consulting" (demo mode: the write is
   simulated and labelled as such).
4. "Run a books health audit and tell me what needs attention."
5. "Prepare my CPA workbook for last year."
