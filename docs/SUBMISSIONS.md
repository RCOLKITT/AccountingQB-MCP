# Directory Submission Runbooks

## Pre-submission checklist (blockers)

- [ ] Privacy policy at accountingqb.com/privacy updated with a remote-service
      section: OAuth handshake metadata only; QuickBooks data is zero-retention
      pass-through; local extension = data never touches our servers.
- [ ] Intuit developer app → "Countries you accept connections from" includes
      Canada (without it Canadian OAuth fails outright).
- [ ] Web app deployed with the OAuth AS routes (/.well-known/oauth-authorization-server,
      /api/oauth2/*, /oauth/authorize) and env: MCP_JWT_SECRET, MCP_RESOURCE_URL,
      NEXT_PUBLIC_REMOTE_MCP_URL.
- [ ] Remote service deployed on Fly (see remote/README.md), DNS
      mcp.accountingqb.com, secrets MCP_JWT_SECRET (same value as Vercel) +
      QB_API_URL=https://accountingqb.com. Verify /healthz and the OAuth
      round-trip with `npx @modelcontextprotocol/inspector`.
- [ ] Reviewer/demo license issued (see below) and smoke-tested.

## Reviewer test account (demo mode)

The server ships a demo mode for reviewers without a QuickBooks account:
any license key equal to `DEMO` or starting with `LK-DEMO-` serves realistic
mock data (company info, P&L, vendors, invoices) and never calls Intuit.
Create a row in `licenses` with key `LK-DEMO-REVIEW2026` (status `active`)
so license validation passes, and hand that key to reviewers. For the remote
connector, register the demo license to a reviewer login so the OAuth consent
flow works end to end.

Three example prompts to include with the submission:
1. "What's my profit and loss for this year?"
2. "Find any uncategorized transactions and suggest categories."
3. "Create a $250 invoice for Acme Consulting" (demo mode: no real write).

## A. Anthropic Connectors Directory (remote connector)

- Endpoint: `https://mcp.accountingqb.com/mcp` (streamable HTTP, stateless).
- Auth: OAuth 2.1 authorization-code + PKCE; Dynamic Client Registration
  (RFC 7591) at accountingqb.com/api/oauth2/register; RFC 9728
  protected-resource metadata served by the MCP host.
- Every tool carries `readOnlyHint`/`destructiveHint` annotations (see
  mcpb/manifest.json, regenerated by scripts/generate-schemas.py).
- Support: support@vasperacapital.com. Docs: accountingqb.com + repo README.
- Submit via Anthropic's connector submission portal; include the demo
  license runbook + example prompts above. Reviews functionally test every
  tool — expect weeks; respond via the status dashboard.

## D. Open-source tail

  `mcp-publisher login dns --domain accountingqb.com --private-key $(doppler secrets get MCP_REGISTRY_PRIVATE_KEY -p accountingqb-mcp -c prd --plain) && mcp-publisher publish` (from the dir holding server.registry.json renamed to server.json).
